# Orb — notes for coding agents

A mobile-first personal assistant derived from JARVIS (Mark LVII) by FatihMakes.
The phone runs a standalone native Kotlin/Compose app that talks directly to Gemini; the Python FastAPI server is optional and only backs the PWA/Capacitor client.

## Run and test

```bash
pip install -r server/requirements.txt
ORB_API_KEY=... python -m server          # http://localhost:8000
python -m pytest server/tests -q
cd native && ./gradlew :app:testDebugUnitTest
```

`python -m server` (not `python server/main.py`) is required: `main.py` uses
relative imports.

## Architecture

- `server/main.py` — HTTP/WebSocket surface only. Keep business logic out of it.
- `server/orb/agent.py` — the conversation loop: history → model → tool calls
  → model → reply. Tool execution is synchronous and runs in a worker thread via
  `asyncio.to_thread` at the route layer.
- `server/orb/llm.py` — every Gemini call. Never construct a `genai.Client`
  elsewhere. The model ladder and the five-minute cooldown are deliberate: a
  quota-exhausted model is skipped, not retried on every turn.
- `server/orb/tools.py` — one `FunctionDeclaration` plus one handler per tool.
  Adding a tool means adding both to `DECLARATIONS` and `HANDLERS`.
- `server/orb/memory.py` — flat JSON entry list, plus capped history.
- `native/app/src/main/java/dev/orb/app/agent/` — the Kotlin agent loop and
  tools. It mirrors `server/orb/agent.py` + `tools.py`; keep the two in sync.
- `native/app/src/main/java/dev/orb/app/data/` — `GeminiClient` (REST model
  ladder), `LocalMemoryStore`, `HistoryStore`, `ApiKeyStore` (encrypted key),
  `SettingsStore`.
- `mobile/www/` — the PWA client. No build step, no framework.
- `native/` — the Android client in Kotlin + Jetpack Compose (Ktor, DataStore,
  AlarmManager, SpeechRecognizer, TextToSpeech).

## Rules that have already caused bugs

- **Paths are resolved at import time.** `settings.DATA_DIR`, `CONFIG_PATH` and
  `MOBILE_DIR` are read when the module loads. Tests must set `ORB_DATA_DIR`
  and `ORB_CONFIG` in `conftest.py` before importing `server`.
- **Route order matters.** `/sw.js` is declared before the `StaticFiles` mount at
  `/`; a new non-static route must also go above the mount.
- **PWA paths are absolute** (`/app.js`, `/icons/...`). Capacitor serves `www/`
  at the origin root, so this is intentional. Do not switch to relative paths
  without checking the native shell.
- **Audio is WAV, 16 kHz, mono, 16-bit.** The browser downsamples before upload
  because Gemini's audio input does not accept WebM/Opus. Do not change the
  client encoder without changing the server's accepted MIME list.
- **Every tool must return a string and must not raise.** `tools.run` catches
  exceptions, but a handler that lies about success is worse than one that
  reports failure.
- **Never return the API key** from `settings.public_settings()`; the UI only
  needs `api_key_set`.
- **The Kotlin app must stay standalone.** Do not reintroduce a server URL,
  token, or `/api/*` dependency into `native/`; it must work with only a Gemini
  key and internet.

## Style

- Python 3.11+, type hints on public functions, `from __future__ import annotations`.
- Comments explain *why*, never restate the code. The original JARVIS files carry
  long design notes; match that spirit, not the length.
- UI text is Portuguese (pt-BR); code and identifiers are English.
- Keep the client dependency-free. If a feature needs a library, justify it.

## Native app

Two Android clients exist. The **Kotlin app in `native/`** is the main one and
is standalone: `dev.orb.app`, Compose UI, Ktor client, direct Gemini REST calls,
EncryptedSharedPreferences for the key, DataStore settings, local alarms and
native voice. It does not call the FastAPI backend. Build it with
`cd native && ./gradlew :app:testDebugUnitTest :app:assembleDebug` (JDK 17 +
Android SDK 35). CI builds `orb-native-debug-apk` in
`.github/workflows/android-native.yml`.

The **Capacitor app in `mobile/android/`** is the hybrid fallback:
`dev.orb.mobile`, same `www/` assets in a WebView. CI builds `orb-debug-apk` in
`.github/workflows/android.yml`.

- `mobile/android/app/src/main/assets/public/` is generated by `npx cap sync`;
  never edit it by hand and never commit it.
- `mobile/ios/` is generated on macOS only and is gitignored.
- The Capacitor manifest allows cleartext HTTP for local development. The Kotlin
  app is HTTPS-only; do not add cleartext or a server URL to it.
- The native app schedules reminders with `AlarmManager`; `BootReceiver`
  reschedules them after a reboot. Reminders are local (`ReminderStore`), never
  fetched from the backend.
- In the native app the Gemini key lives in `EncryptedSharedPreferences` and is
  sent only to Google. In the PWA/backend it lives in `.env`/`config.json` and is
  sent through `PUT /api/config`. Never hardcode a key in the APK.
- The service worker is skipped inside the Capacitor shell (`window.Capacitor`).
